# Prompt 04: 青云计划与顶级技术人才突围矩阵 (Tencent Qingyun Track Protocol)

## 适用对象
面向申请腾讯“青云计划”（前沿技术领军人才计划）、阿里“阿里星”、美团“北斗计划”等顶级校招专项的候选人。

## 考核标准
1. **学术突破 (Academic Horizon)**：顶级学术成果是否具备第一作者原创洞察，能否用 3 句话给不懂该领域的 HR 讲清楚核心贡献。
2. **工程极客力 (Hardcore Engineering)**：不仅会跑实验，更具备深入源码底层的 Debug 能力（如 CUDA Kernel 优化、底层分布式通讯 NCCL 调优）。
3. **技术好奇心与自驱力 (Curiosity & Passion)**：在导师任务之外，过去 12 个月自发调研或复现了哪些业界前沿工作？遇到技术阻碍时的心理韧性。
